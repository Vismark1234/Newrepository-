# Imputación

Se propone mediana para variables numéricas y moda para categóricas como línea base, no como solución universal. Separar entrenamiento y prueba **antes** de ajustar el imputador. Evaluar si la ausencia es estructural, si el dato es recuperable y si imputar tiene sentido de negocio. Las columnas completamente vacías requieren tratamiento específico.
